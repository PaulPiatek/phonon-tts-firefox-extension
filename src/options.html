Model
The English 31M checkpoint is built in. To use another one, pick the folder holding config.json, tokenizer.json, model.q8.gguf and default-voice.safetensors — plus voices.json and voices/ if you want extra voices. Imported files are copied into this browser's storage once, then work offline.

Voices
A voice is a small .safetensors file from gradium/phonon-voices or Gradium Studio. Voices are kept in this browser and shared by every model. Pick the catalog folder (the one with voices.jsonl) to get friendly names.
Speech
Numbers, dates and symbols are read out the way a speaker of this language says them. Pick the language of the text you select.
Lower is steadier, higher is more expressive. The model's default is 0.3.
fasterslower
The model's duration_delta: negative is faster, positive slower. Changing it reloads the model on the next Speak.
Changes save automatically.
Try it
Select text on any page, then click the toolbar button or right-click → 🔊 Spokra. Audio is generated on your device; nothing is sent anywhere.
